# CodeAlpha - Hangman Game 🎯

A simple, interactive, text-based Hangman Game built in Python as part of the **CodeAlpha Internship Program**.

## 📌 Project Overview
The player attempts to guess a secret word one letter at a time. The game provides a limited number of incorrect guesses (6 attempts) before game over.

## ✨ Features
- **Predefined Word Bank:** Selects words randomly from a list.
- **Input Validation:** Handles duplicate entries and invalid characters seamlessly.
- **Attempt Tracking:** Shows remaining incorrect attempts and previously guessed letters.
- **Console Interface:** Clean and easy-to-read command-line output.

## 🛠️ Concepts Used
- Control Flow (`while` loops, `if-else` conditionals)
- Data Structures (`lists`, `strings`)
- Built-in Modules (`random`)
- Input validation and string formatting
